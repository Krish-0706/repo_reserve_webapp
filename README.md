## About The Project

ReServe is a purpose-driven web application designed to bridge the gap between surplus food and those in need. By providing a real-time platform, ReServe connects Food Donors—such as restaurants, caterers, and corporate canteens—directly with verified NGOs and community shelters. 

The platform facilitates seamless communication, logistics tracking, and immediate coordination to ensure that perfectly good food reaches communities rather than landfills.

## Key Features

* **Multi-Role Authentication:** Secure, role-based access control tailored for three distinct user types (Admin, Donor, and NGO/Shelter).
* **Real-Time Dashboards:** Dedicated operational dashboards for each role to manage donations, track claims, and monitor logistics in real-time.
* **Admin Control Panel:** A centralized admin dashboard to verify NGOs, monitor platform activity, and manage users.
* **Streamlined Landing Page:** An engaging and responsive landing page to onboard new donors and shelters.
* **Robust Data Management:** Relational database architecture ensuring reliable transaction records and user data integrity.

## Built With

This project leverages a modern, full-stack web development architecture:

* **Framework:** [Next.js](https://nextjs.org/)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/)
* **Database & Auth:** [Supabase](https://supabase.com/) (PostgreSQL)
* **UI Components:** Built with accessibility and responsiveness in mind (integrating `components.json`).
* **Tooling:** ESLint, PostCSS
